# emergency-broadcast-detector-sdr
# 📡 Emergency Broadcast Detection System using Morse Code and SDR

## 📌 Overview
This project implements a low-cost emergency broadcast detection system using Morse code signaling and Software Defined Radio (SDR). It is designed to operate reliably in low-bandwidth and disaster-prone communication scenarios.

## 🚨 Motivation
During emergencies, conventional communication infrastructure may fail. Morse code remains a robust signaling method under severe noise and bandwidth constraints.

## 🧩 System Architecture
- Morse code message generation (ITU timing standards)
- Baseband signal modulation
- SDR-based transmission and reception
- Signal demodulation and Morse decoding

## 🛠️ Hardware & Software
- ADALM-Pluto SDR
- Python
- GNU Radio / SDR libraries
- NumPy, SciPy

## 🔬 Key Features
- Narrowband signal processing
- Noise-resilient detection
- Real-time decoding capability

## 📊 Results
- Successful detection under low SNR conditions
- Accurate decoding of emergency messages
